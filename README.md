# MST-Clustering
This program is an implementation of MST Clustering on a variety of data sets. It was created during a Data Science Research Project held at UCL in 2026. 

<h4>What is MST Clustering? </h4>
<b><p>Note : This explanation assumes basic knowledge of graphs/networks</p></b>
<p>Clustering is a Data Science technique, where "similar" data is placed into "clusters". There are a lot of different measures to decide what "similar" means, and this program can quite easily adapt to different versions of this, but for this particular program we consider "similar" points to be points that are physically clsoe to each other on a 2D plane (we stuck to 2D to better visualise the Data, but the algorithms in this program are fit for n-dimensional data).</p>
<p>
A minimum spanning tree (MST) is a the graph connecting every single point in a network that also has the smallest total "distance". MST Clustering uses MST's to connect datapoints together, using them as vertices. It is to be noted that these connections don't have to be physical distance, which is why this technique is so useful.
</p>
